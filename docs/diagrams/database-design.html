Design notes

pgvectorchunks.embedding is vector(768). Retrieval orders by cosine distance and takes top_k (default 5).
CascadesAll 1:N links are DB-level ON DELETE CASCADE: deleting an item removes its chunks & jobs; deleting a conversation removes its messages.
Sessionssession_id is the public id used in the UI URL /c/{session_id}; id stays internal.
CitationsStored as jsonb on assistant messages so sources survive reloads. Never replayed to the LLM.
GapsNo ANN index on embedding (sequential scan). ingestion_jobs and content_hash exist but aren't populated.
