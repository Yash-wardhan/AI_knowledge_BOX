  • 3 LLM calls per question — input rail, generation, output rail (+1 embedding call).
  • Rate limits: rails retry 429/5xx with backoff (1.5s, 3s); still failing → HTTP 429 “AI model is busy”.
  • Generation bypasses NeMo: NeMo's Colang 1.0 generation drops system messages, so context/history go via llm_service.
  • Citations: only labels the answer actually cites are returned; stored as jsonb so sources survive reloads.
  • Reload: GET /conversations/{id}/messages restores text + sources; sidebar uses GET /conversations/.
  • Follow-ups: retrieval prepends the previous question so “does it support async?” stays on topic.
